# PilaMatch MVP 개발 요약
**작성일**: 2026-02-10

---

## 프로젝트 개요

**PilaMatch**는 필라테스/요가 강사와 스튜디오를 연결하는 매칭 플랫폼입니다.

### 핵심 가치: **신뢰 (Trust)**
> "작지만 믿을 수 있는 플랫폼"

경쟁사 호호요가의 문제점(불안정성, 검증 부재)을 해결하고, 안전한 거래 환경을 제공합니다.

## 해결한 이슈

### Issue 1: SQLite/PostgreSQL UUID 호환성
**문제**: SQLAlchemy의 PostgreSQL UUID 타입이 SQLite에서 컴파일 실패
```
SQLiteTypeCompiler can't render element of type UUID
```

**해결**: 커스텀 `GUID` TypeDecorator 생성
```python
class GUID(TypeDecorator):
    impl = CHAR(36)
    cache_ok = True
    # UUID를 문자열로 저장, 조회 시 UUID 객체로 변환
```

### Issue 2: SQLAlchemy Enum 타입 충돌
**문제**: 모델의 `SQLEnum`이 PostgreSQL에서 커스텀 타입 생성 시도
```
type "userrole" does not exist
```

**해결**: 모든 Enum 컬럼을 `String(20)`으로 변경
```python
# Before
role = Column(SQLEnum(UserRole), nullable=False)

# After
role = Column(String(20), nullable=False)
```

### Issue 3: Docker entrypoint 권한 문제
**문제**: `permission denied: ./entrypoint.sh`

**해결**:
```bash
chmod +x backend/entrypoint.sh
```

### Issue 4: FastAPI 422 에러 핸들링
**문제**: Frontend에서 validation error 파싱 실패
```
'list' object has no attribute 'get'
```

**해결**: APIError 클래스 개선
```python
if isinstance(detail_content, list):
    # FastAPI validation error format
    errors = [f"{e.get('loc', ['?'])[-1]}: {e.get('msg', 'error')}" for e in detail_content]
```

### Issue 5: 프론트엔드 세션 상태 누락
**문제**: 로그인 후 `st.session_state.user`가 None

**해결**: main() 함수에서 user 로딩 보장
```python
if st.session_state.user is None:
    me = client.get_me()
    st.session_state.user = me.get("user")
```
