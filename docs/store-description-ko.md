# PilaMatch 앱스토어 설명

## 앱 이름

PilaMatch

## 부제

신뢰 기반 필라테스/요가 강사 매칭

## 카테고리

비즈니스 / 건강 및 피트니스

---

## 설명

PilaMatch는 검증된 필라테스/요가 강사와 스튜디오를 안전하게 연결하는 매칭 플랫폼입니다.

본인인증과 사업자인증을 통과한 회원만 참여할 수 있으며, 에스크로 결제와 노쇼 패널티 시스템으로 거래의 안전성을 보장합니다.

### 주요 기능

- **검증된 회원만 참여**: 본인인증(SMS) + 사업자인증으로 신원이 확인된 사용자만 서비스 이용
- **AI 기반 4요소 매칭**: 지역, 경력, 자격증, 희망 급여를 분석하여 최적의 매칭 추천
- **에스크로 결제**: 계약 완료 시까지 결제금을 안전하게 보관, 양측 모두 보호
- **노쇼 패널티 시스템**: 무단 불참 시 패널티 부과로 신뢰 있는 거래 환경 보장
- **Trust Score**: 활동 이력 기반 신뢰도 점수로 상대방을 한눈에 평가
- **프리미엄 멤버십**: 수수료 할인, 무제한 지원/열람, 매칭 부스트 등 추가 혜택

### 강사라면

- 내 경력과 자격에 맞는 스튜디오를 추천받으세요
- 에스크로 결제로 수업료를 안전하게 보장받으세요
- Trust Score를 높여 더 많은 오퍼를 받으세요

### 스튜디오라면

- 검증된 강사 풀에서 최적의 인재를 찾으세요
- 노쇼 패널티로 안정적인 수업 운영을 보장받으세요
- 매칭 알고리즘으로 채용 시간을 절약하세요
