## 1. 에스크로 결제 환불 / Escrow Payment Refunds

PilaMatch는 강사와 스튜디오 간의 안전한 거래를 위해 에스크로 결제 방식을 사용합니다. 에스크로 결제의 환불은 계약 상태에 따라 다음과 같이 처리됩니다.

PilaMatch uses an escrow payment system to ensure safe transactions between instructors and studios. Refunds for escrow payments are processed based on the contract status as follows.

### 1.1 계약 시작 전 취소 / Cancellation Before Contract Start

| 항목 / Item | 내용 / Details |
|------------|---------------|
| **환불 비율 / Refund Rate** | 전액 환불 (100%) / Full refund (100%) |
| **처리 기간 / Processing Time** | 영업일 기준 3~5일 / 3-5 business days |
| **적용 조건 / Conditions** | 계약 상태가 "확정(CONFIRMED)"이며 아직 "진행중(IN_PROGRESS)"으로 전환되지 않은 경우 / Contract status is "CONFIRMED" and has not yet transitioned to "IN_PROGRESS" |
| **수수료 / Fees** | PG사(TossPayments) 결제 취소 수수료가 발생할 수 있음 / PG (TossPayments) cancellation fees may apply |
| **신청 방법 / How to Request** | 서비스 내 [계약 관리] > [취소 요청] / In-app [Contract Management] > [Cancel Request] |

**주의사항 / Note**: 양 당사자 모두 취소에 동의해야 합니다. 일방적 취소 시 운영자 중재가 필요합니다.
Both parties must agree to the cancellation. Unilateral cancellation requires operator mediation.

### 1.2 계약 진행 중 취소 / Cancellation During Contract

| 항목 / Item | 내용 / Details |
|------------|---------------|
| **환불 비율 / Refund Rate** | 쌍방 협의에 따른 비율 환불 / Proportional refund based on mutual agreement |
| **처리 기간 / Processing Time** | 협의 완료 후 영업일 기준 5~7일 / 5-7 business days after agreement |
| **적용 조건 / Conditions** | 계약 상태가 "진행중(IN_PROGRESS)"인 경우 / Contract status is "IN_PROGRESS" |

**처리 절차 / Process**:

1. 일방이 취소를 요청합니다. / One party requests cancellation.
2. 상대방이 취소 및 환불 비율에 동의합니다. / The other party agrees to the cancellation and refund ratio.
3. 합의가 이루어지면 합의된 비율에 따라 환불이 처리됩니다. / Once agreed, the refund is processed according to the agreed ratio.
4. 합의가 이루어지지 않으면 운영자 중재 절차로 전환됩니다. / If no agreement is reached, the case is escalated to operator mediation.

**환불 비율 예시 / Refund Ratio Examples**:

| 상황 / Situation | 스튜디오 환불 / Studio Refund | 강사 정산 / Instructor Settlement |
|-----------------|----------------------------|--------------------------------|
| 강사 귀책 취소 / Instructor-caused cancellation | 100% | 0% |
| 스튜디오 귀책 취소 / Studio-caused cancellation | 0% | 100% (수수료 포함 정산) |
| 쌍방 합의 취소 / Mutual cancellation | 협의 비율 / Agreed ratio | 협의 비율 / Agreed ratio |

### 1.3 계약 완료 후 / After Contract Completion

| 항목 / Item | 내용 / Details |
|------------|---------------|
| **환불 비율 / Refund Rate** | 원칙적 환불 불가 / No refund in principle |
| **예외 / Exceptions** | 분쟁 절차를 통해서만 환불 가능 / Refund only through dispute process |

계약이 "완료(COMPLETED)" 상태로 전환되면 강사에게 정산이 이루어지며, 원칙적으로 환불이 불가합니다. 다만, 중대한 하자가 발견된 경우 본 환불정책 제3조의 분쟁 기반 환불 절차를 이용할 수 있습니다.

Once a contract transitions to "COMPLETED" status, settlement is made to the instructor and refunds are not available in principle. However, if significant defects are discovered, the dispute-based refund process in Section 3 of this policy may be used.

## 2. 프리미엄 구독 환불 / Premium Subscription Refunds

### 2.1 구독료 (월 9,900원) / Subscription Fee (KRW 9,900/month)

| 환불 시점 / Refund Timing | 환불 금액 / Refund Amount | 조건 / Conditions |
|--------------------------|-------------------------|-------------------|
| **결제 후 7일 이내** / Within 7 days of payment | **전액 환불** (9,900원) / **Full refund** (KRW 9,900) | 프리미엄 혜택을 실질적으로 이용하지 않은 경우 / When premium benefits have not been substantially used |
| **결제 후 7일 이후** / After 7 days of payment | **일할 계산 환불** / **Pro-rata refund** | 남은 구독 기간에 비례하여 환불 / Refund proportional to remaining subscription period |

### 2.2 일할 계산 방법 / Pro-rata Calculation Method

```
환불 금액 = 9,900원 x (남은 일수 / 30일)
Refund Amount = KRW 9,900 x (Remaining Days / 30 Days)
```

**계산 예시 / Calculation Examples**:

| 사용 기간 / Days Used | 남은 기간 / Days Remaining | 환불 금액 / Refund Amount |
|----------------------|--------------------------|-------------------------|
| 7일 / 7 days | 23일 / 23 days | 9,900 x (23/30) = **7,590원 / KRW 7,590** |
| 15일 / 15 days | 15일 / 15 days | 9,900 x (15/30) = **4,950원 / KRW 4,950** |
| 25일 / 25 days | 5일 / 5 days | 9,900 x (5/30) = **1,650원 / KRW 1,650** |

### 2.3 프리미엄 혜택의 실질적 이용 판단 기준 / Criteria for Substantial Use of Premium Benefits

7일 이내 전액 환불 시, 다음 중 하나라도 해당되면 "실질적으로 이용한 것"으로 간주하여 일할 계산 환불이 적용될 수 있습니다.

For full refunds within 7 days, if any of the following apply, it may be deemed "substantially used" and a pro-rata refund may apply instead.

- 프리미엄 배지가 적용된 상태에서 계약을 체결한 경우 / A contract was concluded with the premium badge applied
- 프리미엄 수수료율(3%)이 적용된 정산이 이루어진 경우 / Settlement was made with the premium fee rate (3%)
- 일일 지원/열람 제한을 초과하여 프리미엄 무제한 혜택을 이용한 경우 / Unlimited premium benefits were used beyond daily application/viewing limits

### 2.4 자동 갱신 해지 후 환불 / Refund After Auto-renewal Cancellation

1. 구독 해지는 다음 결제일 이전까지 서비스 내에서 신청할 수 있습니다. / Subscription cancellation can be requested within the service before the next payment date.
2. 해지 신청 후에도 현재 결제 기간이 끝날 때까지 프리미엄 혜택이 유지됩니다. / Premium benefits are maintained until the end of the current payment period after cancellation.
3. 이미 결제된 기간에 대해서는 별도의 환불이 이루어지지 않습니다 (7일 이내 환불 규정 제외). / No separate refund is provided for already paid periods (except for the 7-day refund policy).

## 3. 분쟁 기반 환불 / Dispute-based Refunds

### 3.1 분쟁 환불 절차 / Dispute Refund Process

분쟁 기반 환불은 계약 완료 후 또는 일반 환불 규정으로 처리되지 않는 특수한 상황에서 적용됩니다.

Dispute-based refunds apply after contract completion or in special circumstances not covered by the general refund policy.

```
분쟁 신고 접수 -> 이의제기 기간(24시간) -> 운영자 증거 검토 -> 최종 판정 -> 환불 또는 기각
Dispute Filed -> Objection Period (24h) -> Operator Evidence Review -> Final Decision -> Refund or Rejection
```

### 3.2 분쟁 신고 사유 / Grounds for Dispute

| 사유 / Reason | 설명 / Description |
|--------------|-------------------|
| 노쇼(No-show) | 상대방이 합의된 시간/장소에 출석하지 않음 / The other party did not appear at the agreed time/place |
| 서비스 품질 불량 | 계약 내용과 현저히 다른 서비스가 제공됨 / Services significantly different from the contract were provided |
| 허위 정보 | 프로필 또는 공고에 허위 정보가 기재됨 / False information was listed in the profile or posting |
| 기타 계약 위반 | 계약 조건을 중대하게 위반한 경우 / Significant breach of contract terms |

### 3.3 증거 검토 및 판정 / Evidence Review and Decision

1. **증거 수집 / Evidence Collection**: 운영자는 다음 자료를 검토합니다. / The operator reviews the following:
   - 서비스 내 메시지(채팅) 기록 / In-service message (chat) records
   - 계약 상태 변경 이력 (Contract Event Log) / Contract status change history
   - 결제/정산 기록 / Payment/settlement records
   - 이용자가 제출한 추가 증거 / Additional evidence submitted by users

2. **판정 결과 / Decision Outcomes**:

| 판정 / Decision | 조치 / Action |
|----------------|-------------|
| **환불 승인** / Refund Approved | 스튜디오에게 전액 또는 일부 환불, 귀책 당사자에게 패널티 부과 / Full or partial refund to studio, penalty imposed on responsible party |
| **기각** / Rejected | 기존 정산 유지, 신고자에게 기각 사유 통지 / Existing settlement maintained, rejection reason notified to reporter |
| **쌍방 과실** / Mutual Fault | 비율 조정 환불, 쌍방에 경고 / Proportional refund, warning to both parties |

### 3.4 노쇼 관련 환불 특칙 / Special Refund Rules for No-show

| 노쇼 귀책 / No-show Party | 환불 처리 / Refund Processing |
|--------------------------|----------------------------|
| 강사 노쇼 / Instructor No-show | 스튜디오에게 전액 환불 + 강사에게 패널티 30,000원 차감 / Full refund to studio + KRW 30,000 penalty deducted from instructor |
| 스튜디오 노쇼 / Studio No-show | 강사에게 전액 정산 + 스튜디오에게 패널티 30,000원 차감 / Full settlement to instructor + KRW 30,000 penalty deducted from studio |

## 5. 환불 불가 사유 / Non-refundable Cases

다음의 경우에는 환불이 불가합니다. / Refunds are not available in the following cases.

1. 계약 완료(COMPLETED) 후 분쟁 사유 없이 단순 변심에 의한 환불 요청 / Refund request due to simple change of mind after contract completion (COMPLETED) without dispute grounds
2. 이용자의 약관 위반으로 인한 서비스 이용 제한 또는 계정 정지 시 / When service use is restricted or account is suspended due to user's violation of terms
3. 노쇼 패널티로 차감된 금액 (이의제기 기각 시) / Amounts deducted for no-show penalties (when objection is rejected)
4. 보증금 차감분 중 정당하게 부과된 과태료 / Legitimately imposed fines from deposit deductions
5. 서비스 외부에서 이루어진 거래에 대한 환불 요청 / Refund requests for transactions conducted outside the service
