## 1. 피드백 수정 사항

### FB-1: 지난 날짜 공고 표시 개선
- **문제**: 이미 지난 날짜의 공고가 현재 공고와 동일하게 표시됨
- **수정**: 지난 날짜 공고에 취소선 + "지난공고" 라벨 추가, 목록 하단으로 정렬
- **대상**: 센터, 강사 양쪽 공고 목록

### FB-2: 메모 입력 시 제목 즉시 자동완성
- **문제**: 한줄 메모 작성 시 제목이 즉시 반영되지 않음
- **수정**: 메모 입력 시 제목 즉시 자동완성, 프리뷰를 메모 입력란 바로 아래로 이동
- **대상**: 센터 공고 등록 화면

### FB-3: 오퍼 보내기 스크롤 문제
- **문제**: 기존 문서가 많을 경우 오퍼 보내기 클릭 시 스크롤을 내려야 하는 불편함
- **수정**: `st.dialog` 모달 다이얼로그로 교체하여 현재 화면 위에 팝업 표시

### FB-4: 계약 상세 UUID 표시 문제 (이전 세션에서 완료)
- **문제**: 계약 상세에서 강사/스튜디오 ID가 UUID (cdb0c774...)로 표시됨
- **수정**: 활동명 또는 스튜디오명으로 표시하도록 변경
- **상태**: 이미 완료

### FB-5: 수업시간 계산 오류
- **문제**: 02:45~04:00 수업이 "02:45 (1.2시간)"으로 잘못 표시됨
- **원인**: `timedelta.seconds` 대신 `timedelta.total_seconds()` 사용 필요
- **수정**: `.total_seconds()` 메서드로 변경 + 표시 포맷을 "1.25시간"으로 수정
- **예상 결과**: 02:45~04:00 → "1시간 15분 (1.25시간)"
