### 1. 온보딩 단계 표시 버그 수정

#### 문제점
- 새로 가입한 사용자가 Step 1이 아닌 Step 3-4로 표시되는 문제
- 강사는 "3. 지원자 선택", 스튜디오는 "4. 계약 진행"으로 잘못 표시

#### 원인
- API가 NULL 값을 "None" 문자열로 반환
- 프로필 완성도 체크 로직에서 빈 값 처리 미흡
- 예외 처리 시 기본값 설정 누락

#### 해결책
```python
# frontend/app.py 수정
# 1. "None" 문자열 체크 추가
if region == "None" or region is None:
    region = ""

# 2. 예외 처리 개선
except Exception as e:
    data["profile_complete"] = False  # 명시적 기본값 설정
```

## 💡 보증금 제도 심층 분석

### 현재 구현
- **얼리버드**: 30,000원 (2026.05.15까지)
- **정규**: 50,000원
- **노쇼 패널티**: 30,000원 차감
- **계정 정지**: 3회 노쇼 시

### 핵심 딜레마: "신뢰의 역설"

```
플랫폼: "신뢰를 위해 먼저 돈을 내세요"
사용자: "신뢰할 수 있는지 먼저 보여주세요"
```

### 이해관계자별 분석

#### 1. 신규 사용자 관점
**심리적 장벽**:
- 손실 회피 편향 (Loss Aversion)
- 즉각적 손실 vs 불확실한 미래 가치
- "Try → Like → Pay" 기대 vs "Pay → Try" 현실

**전환율 리스크**:
- 예상 이탈 지점: 보증금 결제 단계
- 특히 부업/초보 강사의 진입 장벽

#### 2. 플랫폼 운영자 관점
**법적 리스크**:
- 전자금융거래법 준수 필요
- 약관규제법 (30K 패널티 정당성 입증 필요)
- 개인정보보호법 (탈퇴 시 처리)

**운영 부담**:
- 에스크로 계좌 관리 비용: 연 500만원+
- CS 대응 시간 (환불, 분쟁)
- 1인 창업자에게는 과도한 부담

**숨은 비용**:
```
PG 수수료 (in/out): 1,800원/건
은행 수수료: 420만원/년
기회비용: 1.25억원 × 3% = 375만원/년
```

### 대안 모델 제안

#### 1. 단계적 신뢰 구축 모델 (권장)
```
Level 0: 무료 (본인인증) - 열람만
Level 1: 10,000원 - 3건 제한
Level 2: 30,000원 - 무제한
Level 3: 50,000원 - 프리미엄
```

#### 2. 검증 중심 모델
- 강력한 본인인증 (한국의 장점)
- 평판 시스템 강화
- 보증금은 선택적 프리미엄

#### 3. 수수료 모델
- 보증금 0원
- 거래 수수료 8% (현재 5%)
- Pay-as-you-go

### 전략적 권장사항

#### Phase 1 (즉시)
- ✅ 얼리버드 30K 유지
- ⚠️ 법적 검토 필수
- ⚠️ 비례 패널티 도입 (계약 금액의 30%, 최대 10만원)

#### Phase 2 (3개월)
- A/B 테스트: 보증금 vs 무보증금 그룹
- 데이터 수집: 전환율, 노쇼율, 수익성

#### Phase 3 (6개월)
- 데이터 기반 최종 모델 결정
- 보험 상품 도입 검토

### 핵심 인사이트

1. **보증금 효과성**: 6.5/10점
   - ✅ 품질 필터링 효과
   - ❌ 선량한 사용자도 차단
   - ❌ 패널티가 계약 금액과 비례하지 않음

2. **법적 준비 필요**:
   - 약관 법률 검토 필수
   - 패널티 = 실손해 입증 필요
   - 에스크로 회계 분리 필요

3. **1인 창업자 관점**:
   - 운영 복잡도 vs 성장 속도 트레이드오프
   - 자동화 가능한 신뢰 메커니즘 우선
   - 데이터 기반 의사결정 체계 구축

## 📊 강사 보호 기능 분석

### 현재 강사 보호 수준
✅ **잘 보호되는 부분**:
- 에스크로를 통한 100% 수업료 보장
- 부당 완료/노쇼 신고에 대한 24시간 이의신청권
- 양방향 완료 확인 시스템

❌ **보호 공백**:
- 스튜디오 노쇼에 대한 보상 없음
- 당일 취소 시 보상 없음 (기회비용 손실)
- 스튜디오 품질 검증 부재

### 제안된 개선사항

1. **스튜디오 노쇼 패널티 시스템**
   - 스튜디오도 보증금 의무화
   - 노쇼 시 강사에게 50% 보상
   - 3회 노쇼 시 계정 정지

2. **취소 수수료 정책**
   ```
   24시간+ 전: 0% (수수료 없음)
   12-24시간 전: 30% 강사 보상
   12시간 내: 50% 강사 보상
   ```

3. **스튜디오 검증 뱃지**
   - 시설 인증
   - 안전 점검
   - 장비 보유 확인
