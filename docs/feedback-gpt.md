## 해결 (반드시 추가해야 함)

### 🔥 “Auto Dispatch Engine” (이게 핵심 feature다)

```
1. 긴급 호출 버튼 클릭
2. 1차 후보 5명 자동 발송
3. 3분 내 미응답
4. 2차 후보 확장 (거리 증가)
5. 자동 accept (선착순 or 최고점)
6. 확정
```

👉 이거 없으면 절대 119 아니다
